EGZAMIN OFICERSKI — PWA

Pliki:
- index.html — baza pytań
- manifest.webmanifest — konfiguracja instalacji PWA
- sw.js — obsługa offline
- icons/ — ikony aplikacji

Instalacja na iPhone:
1. Wgraj cały folder na hosting HTTPS, zachowując strukturę plików.
2. Otwórz adres index.html w Safari.
3. Wybierz Udostępnij -> Dodaj do ekranu głównego.
4. Uruchom aplikację z nowej ikony.
5. Po pierwszym pełnym uruchomieniu aplikacja może działać offline.

Uwaga: postęp jest zapisywany lokalnie w pamięci witryny/PWA na danym urządzeniu. Wbudowany eksport/import postępu służy do przenoszenia kopii między urządzeniami.
